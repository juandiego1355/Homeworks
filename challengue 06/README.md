# Challenge 06 — Árboles y nodos

Proyecto Angular para practicar un árbol binario de búsqueda con nodos, recorridos y visualización con D3.

## Requisitos

```bash
npm install
npm start
```

## Funcionalidades implementadas

- Inserción de valores en un árbol binario.
- Recorridos `inorder`, `preorder` y `postorder` en consola.
- Verificación de si un valor existe en el árbol.
- Visualización del árbol usando `d3` y `d3-hierarchy`.
