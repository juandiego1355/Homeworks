# Nexo — personas y ciudades

Aplicación Angular que crea un grafo interactivo de personas y ciudades. Cada persona tiene nombre y edad, y queda vinculada a una ciudad. El listado se puede filtrar por ciudad; selecciona una ciudad en el grafo para aplicar el mismo filtro.

## Ejecutar

```bash
npm install
npm start
```

La aplicación inicia con datos de ejemplo. Añade ciudades y personas desde el panel lateral; el grafo se actualiza al instante y sus nodos se pueden arrastrar.

## Compilar

```bash
npm run build
```
