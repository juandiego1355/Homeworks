# Challenge 12 — Prisma

Aplicación Angular que combina un Trie para encontrar productos por prefijo con un min-heap acotado para mostrar los K productos más populares.

## Ejecutar

```bash
npm install
npm start
```

La búsqueda funciona al escribir. El catálogo incluye productos de ejemplo y permite añadir productos con popularidad de 0 a 100.

## Compilar

```bash
npm run build
```
